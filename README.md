# TypeBridge 跨屏输入

手机打字 / 语音 → 电脑光标处直接出字；手机图片/文件 → 一键传到电脑并自动粘贴，不用数据线、不用装驱动。

## 为什么做

在电脑上打字/发消息时，最烦的是从电脑切到手机（或反过来）。TypeBridge 让手机变成一个"无线键盘 + 语音输入器 + 传图通道"：手机连电脑同一个 WiFi，扫码配对，手机输入法的文字/语音直达电脑光标处，照片拍完立刻出现在电脑的聊天输入框里。

## 版本

- **Windows 版**：`src/TypeBridge.cs`（C#5，无需第三方依赖），右下角托盘常驻，托盘菜单：状态行（版本/地址/连接状态）/ 获取更新 / 打开手机扫码连接页面 / 重新生成配对码 / 暂停注入 / 选择网络 / 开机自启 / 查看日志 / 打开接收文件夹 / 最近接收。
- **麒麟版**：`kylin/typebridge.py`（Python3 标准库），`kylin/install.sh` 一键安装（全程自动、零输入，创建桌面图标和开机自启）。
- 两版共有的手机端能力（v0.4，合并自 AirType）：打字/语音实时同步、**图片/文件传输**（大图智能压缩、进度、取消、失败自动重试）、**电脑扫码页远程控制**（断开手机 / 重新配对 / 打开接收文件夹）、输码连接（扫不了码时手输 4 位配对码）、深色主题手机端、省电模式。

## 怎么用

1. 电脑和手机连同一个 WiFi。
2. Windows：双击 `build/TypeBridge.exe`，自动弹出扫码窗口；麒麟：运行安装脚本后双击桌面图标。
3. 手机浏览器打开电脑上显示的二维码地址（或直接输配对码），出现绿点"已连接"。
4. 手机上有两种模式：
   - **手动发送**：打完字点"发送"，文字到电脑光标处。
   - **实时同步**：边说边到电脑，停顿 2.5 秒可自动清空输入框（默认关，可开）。
   - 支持回车、退格、撤回（只能撤自己发的内容，换窗口后失效）；支持中文输入法语音输入。
5. **图片/文件 → 电脑**：手机上点「图片→电脑」选照片（可拍照），文件传到电脑的
   `下载\TypeBridge接收` 文件夹；图片会自动粘贴到电脑当前光标处（微信聊天框、Word 里直接出图）。
   大图自动压缩（可选"原图"），带进度和取消，失败自动重试一次。

## 电脑扫码页

在电脑上打开 `http://localhost:8765/pair`（或托盘菜单），除了二维码还有：

- 连接状态实时显示（绿点=手机已连接）。
- **断开当前手机** / **重新配对**（换新码并踢掉旧连接，旧设备不重新拿码进不来）。
- **打开接收文件夹**：直接跳到接收目录。
- 手机端连不上时也可以不扫码，直接在手机页输入 4 位配对码连接。

## 多网络 / 代理用户

机器上有多个网络（多网卡、VPN、Clash 等代理的 TUN 虚拟网卡）时，自动挑的 IP 可能手机连不上：

- **Windows**：托盘右键 →「选择网络」，选中真正上网的那块网卡（会记住，下次启动还用它）；配对页上也会列出全部备选地址，扫码不行就换一个。
- **麒麟**：启动时加 `--ip 192.168.x.x` 指定（会记住）；或打开配对页，页面下方列出了所有网络地址，哪个能连用哪个。

## 启动行为

- 已开启开机自启：开机后**静默**在后台待命，不弹窗、不再询问；需要扫码时右键托盘图标（Windows）或双击 TypeBridge 图标（麒麟）即可。
- 开机自启的询问只在**第一次运行**时出现一次，之后不再打扰，想改随时用托盘菜单开关（Windows）或重新运行安装脚本（麒麟）。

## 自己编译

Windows（需要 .NET Framework 4.x，系统自带 csc）：

```bat
build\build_stage1.bat
```

麒麟：直接 `python3 kylin/typebridge.py` 运行，或 `bash kylin/install.sh` 一键安装。

## 目录结构

```
src/          Windows 版源码 + 手机端页面
kylin/        麒麟版源码 + web + 一键安装脚本
build/        编译好的 Windows 程序 + 编译脚本
docs/         宣传文案与实施方案
spike/        自动化测试脚本
```

## 说明

- 端口 8765，纯局域网通信，数据不经过任何服务器。
- 配对码 4 位数字，防止同一 WiFi 下其他人误连。
- 麒麟 Wayland 会话需要 `wl-clipboard`（安装脚本会自动装；手动装：`sudo apt install wl-clipboard`）。
