# TypeBridge 跨屏输入 · 统信 UOS 安装与使用说明

> 手机打字 / 说话 / 传图片文件 → 直接出现在电脑上（光标处），不用数据线、不用装驱动。
> 数据只在手机和电脑之间直连传输，**不经过任何服务器**。
> 银河麒麟系统同样适用本说明（同一套程序）。

---

## 一、安装前确认三件事

| 确认项 | 说明 |
|---|---|
| 系统版本 | 统信 UOS 桌面版（专业版 / 家庭版均可），X11 或 Wayland 会话都可以装 |
| 有管理员密码 | 安装系统依赖和 deb 包时需要输入一次（就是登录电脑的密码） |
| 手机在身边 | 安装完要用手机扫码或输码连接 |

---

## 二、安装（两种方式二选一）

### 方式一：deb 安装包（推荐，约 1 分钟）

拿到网盘里的 `typebridge_0.7_all.deb` 文件后：

**最简单：双击安装**
1. 在文件管理器里找到 `typebridge_0.7_all.deb`，**双击**它。
2. 弹出"软件包安装器"后点 **安装**，输入开机密码，等待完成。

**或者：终端安装**
1. 在 deb 文件所在的文件夹里**右键 → 打开终端**（或在终端里 `cd` 到该目录）。
2. 输入：
   ```bash
   sudo apt install ./typebridge_0.7_all.deb
   ```
3. 输入开机密码，等待完成。装完会提示"TypeBridge 安装完成"。

> 联网状态下安装会自动补齐所需工具（xdotool 等）；**内网无软件源**的机器也能装上主程序，
> 但要正常打字还需管理员装上 `xdotool`（见第六节排查）。

### 方式二：文件夹脚本安装（拿到的是整个 TypeBridge 文件夹时）

1. 把拿到的整个文件夹（里面有 `install.sh`、`typebridge.py`、`web/`）拷到统信电脑上，比如放桌面。
2. 打开终端（桌面右键 → 打开终端，或开始菜单搜"终端"）。
3. 执行（把路径换成你实际放的位置）：
   ```bash
   cd ~/桌面/kylin        # 或你放的位置
   bash install.sh
   ```
4. 向导全程自动：检测环境 → 弹**一次**管理员密码框补装依赖 → 装程序 → 建桌面图标 →（询问一次是否开机自启）→ 完成后自动启动并弹出配对页。

> 两种方式装哪个都行。deb 装到系统目录（开始菜单启动），脚本装到用户目录（桌面图标启动），互不冲突。

## 三、手机连接（第一次使用）

1. **让手机和电脑连同一个 WiFi**（手机不能开流量；同一办公室/家里 WiFi 即可）。
2. 电脑上启动：
   - deb 安装：点**开始菜单 → TypeBridge 跨屏输入**。
   - 脚本安装：**双击桌面的 TypeBridge 图标**。
   - 启动后会自动弹出配对二维码页面（电脑没弹就在电脑浏览器打开 `http://localhost:8765/pair`）。
3. 用手机的 **微信「扫一扫」或相机** 扫电脑上的二维码，手机浏览器会打开输入页面。
4. 手机页面出现绿点 **「已连接」** 就通了，直接在手机输入框打字 / 按住说话，文字实时出现在电脑光标处。

**扫不了码？** 手机浏览器地址栏直接输入电脑上显示的地址（形如 `http://192.168.x.x:8765/m?code=1234`），
或点手机页面的「输码连接」，输入屏幕上的 **4 位配对码**。

## 四、日常使用

| 功能 | 怎么用 |
|---|---|
| **打字** | 手机输入框打完点「发送」，或切「实时同步」边打边出字 |
| **语音输入** | 手机输入法的麦克风按住说话（实时同步模式下边说边出字） |
| **回车 / 退格 / 撤回** | 手机下方三个按键；撤回=删掉上一次发送的内容 |
| **图片 → 电脑** | 点「图片→电脑」选照片（可拍照），图片自动保存并**粘贴到电脑当前光标处**（微信聊天框、文档里直接出图） |
| **文件传输** | 同上入口，任何文件最大 200MB，保存到电脑的 **下载 / TypeBridge接收** 文件夹 |
| **换配对码 / 断开手机** | 电脑上打开 `http://localhost:8765/pair`，页面上有按钮 |
| **输码连接** | 扫码不方便时，手机页面直接输 4 位配对码 |

## 五、开机自动运行（推荐设置）

设置一次，以后开机电脑自动在后台待命，手机随时扫码就能用：

```bash
typebridge --install-autostart
```

取消自启：

```bash
typebridge --uninstall-autostart
```

> 开机自启后**不会弹任何窗**，安静地在后台待命；要扫码时再点一次开始菜单的 TypeBridge 图标即可。
> （脚本安装的用户把命令换成 `python3 ~/.local/share/typebridge/typebridge.py --install-autostart`）

## 六、手机连不上？按顺序排查

1. **确认手机和电脑连的是同一个 WiFi**，手机没开流量、没开代理（VPN/加速器关掉再试）。
2. 电脑上打开终端，跑环境自检（只检查不注入）：
   ```bash
   typebridge --selfcheck        # 脚本安装: python3 ~/.local/share/typebridge/typebridge.py --selfcheck
   ```
   - 显示「将使用通道 [xxx]」= 环境正常，回到第 1 条检查网络；
   - 显示「不可用」并给出提示的，按提示装对应工具（最常见：`sudo apt install xdotool`，装完重跑自检确认）。
3. **Wayland 会话**（自检里会话类型显示 wayland，新版 UOS 默认）如果各种工具都装了还打不出字：
   **注销** → 回到登录界面 → 点密码框旁/右下角的**会话选择器 → 选 X11** → 重新登录，再跑自检。X11 兼容性最好。
4. 电脑端日志在 `~/.config/typebridge/log.txt`，发给支持人员能快速定位。
5. 拿到新机器/换机器时，可运行环境采集脚本 `collect_env.sh`（随文件夹附带），
   生成 `typebridge_env_report.txt` 发给支持人员，远程即可判断缺什么。

## 七、常见问题

**Q：打字没反应，手机上显示"已发送"？**
电脑端注入通道没就绪。跑 `typebridge --selfcheck`，按提示装工具（通常是 `sudo apt install xdotool`）。

**Q：怎么卸载？**
```bash
# deb 安装的：
sudo apt remove typebridge

# 脚本安装的：
python3 ~/.local/share/typebridge/typebridge.py --uninstall-autostart
rm -rf ~/.local/share/typebridge ~/.local/share/applications/typebridge*.desktop
# 再删掉桌面上的 TypeBridge 图标即可
```

**Q：公司内网/家里有多个网络，手机扫了连不上？**
电脑二维码选错了网卡。启动时指定（会记住）：
```bash
typebridge --ip 192.168.x.x     # 换成电脑上"手机能访问到"的那个地址
```
或打开配对页，页面下方列出了所有备选地址，手机直接打开能通的那个。

**Q：接收的文件在哪里？**
默认在 文件管理器 → **下载 → TypeBridge接收**。脚本安装的可自定义：
```bash
python3 typebridge.py --recv-dir ~/文档/跨屏接收    # 路径随意，会记住
```

**Q：安全吗？会不会传到网上？**
不会。手机和电脑点对点直连，数据不经过任何服务器；还有 4 位配对码防止同网络的其他人误连。
