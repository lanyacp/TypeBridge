## 手机打字、说话，直接出现在电脑光标处——现在 Windows、麒麟、统信都能用

写材料打到一半，要拿手机里的信息，来回切屏幕、发微信自己，一天下来不知道多少次；

开会用电脑投屏，想让手机里的语音速记上屏，只能干瞪眼；

用微信传了张截图到电脑，还要先保存、再打开文件夹、再拖进聊天框……

**TypeBridge 就是为了解决这些碎事**：手机扫码连上电脑，之后——

- 手机上**打字、语音转文字**，实时出现在电脑光标处；
- 手机选张**照片**，自动保存并**直接粘贴到电脑当前光标处**（微信聊天框、Word 里直接出图）；
- 传**文件**也顺手搞定，最大 200MB，自动存到接收文件夹；
- 回车、退格、撤回都是手机上的按键，打错了手机上删就行。

不需要数据线，不需要装手机端 App（手机用微信扫一扫就行），**数据只在手机和电脑之间直连，不经过任何服务器**，还有 4 位配对码防止同 WiFi 的其他人误连。

## 用起来就三步

1. 电脑上启动 TypeBridge（Windows 双击 exe；麒麟/统信点开始菜单的 TypeBridge）；
2. 手机和电脑连**同一个 WiFi**，微信扫电脑上的二维码；
3. 手机上出现绿点「已连接」，打字或按住说话——字就到电脑光标处了。

扫不了码？手机浏览器直接输电脑上显示的地址，或输 4 位配对码，一样能连。

## 这版（v0.8）解决了什么

- **打字时误触了鼠标/触摸屏，文字进了错误窗口？** 新增焦点切换保护：检测到电脑窗口切换，立即停止灌入并自动切回手动发送——**文字还完整留在手机输入框里**，放好光标点「发送」或点新增的「重发」按钮，全文一次到位，不用重打；Windows 托盘也加了「重放上次输入」。
- **扫码后打不开**的头号原因（防火墙没放行）：Windows 版加了「一键修复」，启动时也会自检提醒；
- 电脑换了 WiFi 后二维码地址会**自动跟随变化**，手机页自动刷新；
- 托盘弹窗打开**第一眼就是二维码**，不用再下拉；
- Win10 托盘图标不显示的问题修了，exe 也有了自己的图标；**Win7 没升级 IE8 的老机器也能出二维码**（绘制自动降级）；
- 新增统信 UOS 适配：安装向导自动识别发行版，Wayland 会话给出一键切回 X11 的指引，还提供 deb 包方便企业 IT 走内网源统一推送。

## 几个常见问题

**安全吗？** 手机和电脑点对点直连，数据不过服务器；换新配对码即可让旧设备失效。

**公司电脑没外网/走内网源？** Linux 版提供 deb 包和内网源搭建说明（包内文档），IT 可以统一推送。

**打字没反应？** 跑一下环境自检（Linux：`typebridge --selfcheck`；Windows 一般不会遇到，遇到就点托盘「一键修复」），按提示装一个开源小工具即可。

**怎么卸载？** Windows 删掉 exe 就完事（无残留）；Linux 一条 `sudo apt remove typebridge`。
